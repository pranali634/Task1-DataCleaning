# Task1-DataCleaning
Data Cleaning and Preprocessing project using Python Pandas. This project includes handling missing values, removing duplicates, standardizing data formats, cleaning column names, and generating a cleaned dataset ready for analysis.

## Objective
Clean and preprocess raw dataset using Python Pandas.

## Steps Performed
- Removed duplicate rows
- Handled missing values
- Standardized column names
- Checked data types
- Saved cleaned dataset

## Tools Used
- Python
- Pandas

## Output
Generated cleaned_dataset.csv
